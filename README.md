## 🚀 Featured Projects

### 1. InfraEye — Enterprise LAN Monitoring & Asset Intelligence
Took end-to-end ownership to build an enterprise LAN monitoring platform currently managing 2,000+ endpoints. Features a master-agent architecture (Watchdog-Worker pattern on Windows), live CPU/RAM/disk charts via Recharts, and automated Excel reporting that cut audit prep from 3 hours to 2 minutes.
- **Stack:** FastAPI, React 18, MongoDB, Python, PyInstaller, Framer Motion

### 2. TaskFlow — Team Task Management System
A Kanban-based team productivity platform with drag-and-drop task management, a 3-tier role system, real-time notifications, and full audit trails. Validated with 40+ tasks at 100% reliability and sub-200ms API response times.
- **Stack:** React.js, Node.js, Express.js, MongoDB, JWT Auth, Tailwind CSS
- **Links:** [Live Demo](https://taskflow-ctm.vercel.app/) | [GitHub Repo](https://github.com/Ethical-21/taskflow-app)

### 3. Flavour with Fusion — AI Meal Planner
An AI-powered recipe platform using a 3-tier resolution engine (Spoonacular → Custom DB → Groq/LLaMA) to guarantee zero empty results. Features dietary customization, AI ingredient substitution, and a drag-and-drop weekly meal planner.
- **Stack:** Next.js, TypeScript, Firebase Auth, Groq API, LLaMA
- **Links:** [Live Demo](https://flavour-with-fusion-eight.vercel.app/) | [GitHub Repo](https://github.com/Ethical-21/flavour-with-fusion)
