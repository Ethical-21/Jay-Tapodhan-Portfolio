## 🎨 About This Portfolio

This repository isn't just a basic static site; it's a living interface. It features:
- **Neural Network UI:** An interconnected, glowing "Neural Glassmorphism" aesthetic built with native CSS grid geometry.
- **Interactive Canvases:** Responsive HTML Canvas backgrounds featuring lattice grids and hex networks.
- **Scroll Physics:** Cinematic reveal animations, animated SVG data rings, and smooth horizontal progress bars running on `framer-motion`.
- **Modern Architecture:** Built on React 19 + TypeScript + Vite for ultra-fast HMR and production bundling.
